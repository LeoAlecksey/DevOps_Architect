# devops-architect-templates

Шаблоны и материалы лабораторных курса DEVOPS ARCHITECT.

Здесь лежит то, что нужно студенту рядом с курсом на Stepik: брифы, подсказки, рубрики, шаблоны документов. Инструмент проверки и пулы отказов живут в отдельном репозитории.

## Структура

```
m00/
  BRIEF.md              бриф лаборатории M0
  HINTS.md              подсказки по этапам, три уровня
  RUBRIC.md             рубрика самооценки
  stage-contract.yaml   контракт этапов
  templates/            шаблоны: ADR, postmortem, замеры, манифест, схема status
```

Каждый следующий модуль добавляется каталогом `m01/`, `m02/` и так далее.

## Как пользоваться

Берите шаблон из `templates/`, копируйте в свой репозиторий `lab-infra` и заполняйте. Значения в примерах вымышленные.

## Версии

Материалы привязаны к изданию курса. Издание указано в теге репозитория.
